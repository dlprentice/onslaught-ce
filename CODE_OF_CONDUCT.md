# Code of Conduct

Status: active
Last updated: 2026-11-11
Summary: this project follows the Contributor Covenant 2.1, and unacceptable behaviour is reported privately to the maintainer through the repository's private report form.

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
It applies in this repository's Discussions, Issues and pull requests, and wherever someone speaks for the project.

To report unacceptable behaviour, use this repository's private report form: on the repository's Security tab choose
**Report a vulnerability**, or open
[the form directly](https://github.com/dlprentice/onslaught-ce/security/advisories/new). Reports go privately to the
maintainer. If you would rather use email, write to the project inbox, <onslaughtce@gmail.com>.
